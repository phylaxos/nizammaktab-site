# nizammaktab.online

Landing page for **Nizam Maktab** — school management software for Pakistan.

Single self-contained `index.html` (~15 KB, no build step, no external requests).
Published with GitHub Pages from the `main` branch, root folder.

## Deploy
Settings → Pages → Source: `main` / `/ (root)`.
`CNAME` binds the custom domain; enable *Enforce HTTPS* once the cert issues.

## DNS (apex domain)
A records → 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153
CNAME     → www → <username>.github.io
